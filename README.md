# leetcode重做助手

复习力扣题目时，经常会先看到上次写过的代码。这个插件会在打开题目时，将有改动的代码恢复为初始模板，方便重新思考和作答。

目前仅支持 **Chrome 浏览器**，适用于力扣中国站。

## 安装

1. 在仓库页面点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择解压后包含 `manifest.json` 的文件夹。
4. 打开或刷新力扣中国站的题目页，即可使用。

## 使用

- 插件默认开启，进入题目或切换编程语言时，会自动检查并恢复初始模板；未改动的模板不会重置。
- 点击工具栏中的插件图标，可以开关自动恢复、显示或隐藏右下角运行提示，也可以手动重新检查。
- 如果需要保留正在写的代码，请先关闭“自动恢复初始模板”，再刷新页面或切换语言。
